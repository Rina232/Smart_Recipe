# Описание продукта (Product)

## 1. Назначение
Smart Recipe - веб-приложение для интеллектуального подбора рецептов на основе запроса пользователя и имеющихся ингредиентов.

Система помогает пользователю подобрать подходящий рецепт и получить информацию, необходимую для его приготовления, на основе указанных ингредиентов.

## 2. Пользователи 

- **Посетитель** — не вошёл в аккаунт и ещё не выбрал вход в качестве гостя.
- **Гость** — открыл чат через вход в качестве гостя. Доступен один чат, который сохраняется при перезагрузке страницы.
- **Зарегистрированный пользователь** — вошёл в аккаунт или успешно зарегистрировался. Его чаты отображаются в сайдбаре.
- **Администратор** — вошёл в аккаунт администратора. Доступны функции обычного пользователя и панель администратора.

## 3. Задача пользователя

Основная задача пользователя — получить подходящий рецепт по текстовому запросу.

Пользователь может указать имеющиеся продукты, желаемое блюдо или другие пожелания к рецепту. Система должна подобрать релевантную информацию и сформировать понятный ответ с рецептом.

## 4. Основной сценарий

1. Пользователь открывает Smart Recipe.
2. Пользователь входит в аккаунт, регистрируется или продолжает работу в качестве гостя.
3. Пользователь открывает новый чат.
4. Пользователь вводит запрос с описанием желаемого блюда или имеющихся ингредиентов.
5. Система обрабатывает запрос и подбирает подходящие рецепты.
6. Пользователь получает сформированный ответ с рецептом.
7. Пользователь может продолжить взаимодействие в текущем чате.

## 5. Границы первой версии

В первой версии Smart Recipe планируются:

- вход и регистрация пользователей;
- возможность работы в качестве гостя;
- создание и использование чатов;
- ввод текстового запроса;
- подбор рецептов по запросу пользователя;
- отображение результата в виде ответа с рецептом;
- сохранение чатов зарегистрированного пользователя;
- административная часть приложения.

## 6. Проверяемые требования

Первая версия продукта будет считаться работоспособной, если:

1. Пользователь сможет открыть приложение и выбрать способ входа.
2. Гость сможет открыть чат и отправить запрос без регистрации.
3. Зарегистрированный пользователь сможет создавать и открывать свои чаты.
4. Пользователь сможет отправить текстовый запрос на подбор рецепта.
5. После обработки запроса система отобразит пользователю результат.
6. Администратор сможет открыть административную панель.
