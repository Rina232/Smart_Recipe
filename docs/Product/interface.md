# Описание интерфейсов (System Design Document)

Документ описывает визуальную структуру экранов Smart Recipe и их состояния. Базовые токены и компоненты определены в каноничных файлах:

- Цветовые токены: [`/docs/Product/ui/colors.md`](/docs/Product/ui/colors.md)
- Типографика: [`/docs/Product/ui/typography.md`](/docs//Product/ui/typography.md)
- Базовые UI-компоненты: [`/docs/Product/ui/components.md`](/docs/Product/ui/components.md)

## 1. Визуальные основы

- **Фоны:** `surface-0` для фона страниц, `surface-1` для карточек и боковой панели, `surface-highlight` для выделенных поверхностей.
- **Текст:** `text-main`, `text-muted` (цвет `charcoal-900` с непрозрачностью 70%) и `text-inverse`.
- **Акценты:** `primary`, `secondary`, `tertiary`, `border-main`.
- **Статусы:** `status-success`, `status-warning`, `status-danger`, `status-critical`.
- **Типографика:** заголовки используют стили `Heading/H0`–`H3`, интерфейсный и основной текст — стили `Body/*`, `Label/*`, `Caption/*` из `typography.md`.

Размеры и оформление кнопок, полей ввода, подсказок, боковой панели, карточек рецептов, индикаторов и KPI-карточек соответствуют `components.md`. В этом документе указаны только особенности их внешнего вида на конкретных экранах.

## 2. Экраны

### 2.1. Вход (`/login`)

```text
+-----------------------------------------------------------------------+
| Smart Recipe                                                          |
|                                                                       |
|                        +-----------------------+                      |
|                        |  Добро пожаловать!    |                      |
|                        |                       |                      |
|                        |  Логин                |                      |
|                        |  [                  ] |                      |
|                        |                       |                      |
|                        |  Пароль               |                      |
|                        |  [               (o)] |                      |
|                        |                       |                      |
|                        |  [       Войти      ] |                      |
|                        |  [ Войти как гость  ] |                      |
|                        |                       |                      |
|                        |  Ещё нет аккаунта?    |                      |
|                        |  Зарегистрироваться   |                      |
|                        +-----------------------+                      |
|                                                                       |
+-----------------------------------------------------------------------+
```

- Фон страницы: `surface-0` с паттерном продуктовых иконок.
- Логотип «Smart Recipe» расположен в левом верхнем углу, стиль `Heading/H1`, цвет `text-main`.
- Карточка формы расположена по центру страницы: фон `surface-1`, скругление `0.75rem`, рамка `1px solid border-main`.
- Заголовок карточки: «Добро пожаловать!», стиль `Heading/H1`.
- Поля «Логин» и «Пароль» оформлены согласно компоненту поля ввода. В поле пароля справа расположена иконка видимости.
- Кнопка «Войти» использует вариант `primary`; «Войти как гость» — `secondary`. Обе кнопки занимают ширину карточки.
- Ссылка «Зарегистрироваться» оформлена цветом `primary`; поясняющий текст — `text-muted`.

### 2.2. Регистрация (`/register`)

```text
+-----------------------------------------------------------------------+
| Smart Recipe                                                          |
|                                                                       |
|                        +-----------------------+                      |
|                        |  Создание аккаунта    |                      |
|                        |                       |                      |
|                        |  Отображаемое имя     |                      |
|                        |  [                 !] |                      |
|                        |  Текст ошибки...      |                      |
|                        |                       |                      |
|                        |  Логин                |                      |
|                        |  [                 !] |                      |
|                        |  Текст ошибки...      |                      |
|                        |                       |                      |
|                        |  Пароль               |                      |
|                        |  [               (o)] |                      |
|                        |  [===] [===] [===]    |                      |
|                        |  Очень слабый пароль  |                      |
|                        |                       |                      |
|                        | [Зарегистрироваться]  |                      |
|                        |  [ Войти как гость  ] |                      |
|                        |                       |                      |
|                        |  Уже есть аккаунт?    |                      |
|                        |  Войти                |                      |
|                        +-----------------------+                      |
|                                                                       |
+-----------------------------------------------------------------------+
```

- Фон, логотип и карточка соответствуют экрану входа.
- Заголовок карточки: «Создание аккаунта», стиль `Heading/H1`.
- Поля «Отображаемое имя», «Логин» и «Пароль» оформлены согласно компоненту поля ввода.
- В показанном состоянии ошибки поля выделены рамкой `status-danger`, рядом отображается иконка `!`; текст ошибки расположен под полем, стиль `Caption/Regular`, цвет `status-danger`.
- Тексты ошибок:
  - «Имя должно содержать от 3 до 30 символов».
  - «Имя должно содержать только буквы, пробел, дефис или апостроф».
  - «Логин должен содержать от 3 до 30 символов».
  - «Логин должен содержать только латинские буквы, цифры, дефис или подчёркивание».
- Индикатор надёжности пароля выглядит согласно компоненту из `components.md`.
- Кнопка «Зарегистрироваться» использует вариант `primary`; «Войти как гость» — `secondary`.
- Ссылка «Войти» оформлена цветом `primary`; поясняющий текст — `text-muted`.

### 2.3. Новый чат (`/chat/new`)

```text
+------------------+----------------------------------------------------+
| [||] ЧАТЫ        |                                                    |
| ---------------- |                                                    |
| + Новый чат      |                                                    |
| ---------------- |                    Smart Recipe                    |
| Корейские блюда  |       Что бы вы хотели сегодня приготовить?        |
| Идеи для диеты   |                                                    |
|                  |    +----------------------------------------+      |
|                  |    | Напишите, что хотите приготовить... [^]|      |
|                  |    +----------------------------------------+      |
|                  |                                                    |
| [Панель админа]  |                                                    |
+------------------+----------------------------------------------------+
```

- Сайдбар показан в развёрнутом состоянии с шириной `clamp(16rem, 20vw, 18.25rem)`.
- Фон сайдбара — `surface-1`; его правая граница — `1px solid border-main`.
- В сайдбаре расположены заголовок «ЧАТЫ», кнопка создания чата, список чатов и кнопка панели администратора.
- Центральный блок содержит логотип «Smart Recipe» в стиле `Heading/H0` и подзаголовок «Что бы вы хотели сегодня приготовить?» в стиле `Body/Regular`, цвет `text-muted`.
- Поле ввода занимает доступную ширину блока. Плейсхолдер: «Напишите, что хотите приготовить или какие продукты у вас есть...».
- Кнопка отправки с иконкой стрелки вверх имеет круглую форму и заливку `primary`.

### 2.4. Активный чат (`/chat/:id`)

```text
+------------------+----------------------------------------------------+
| [||] ЧАТЫ        |                                  +--------------+  |
| ---------------- |                                  | Текст запроса|  |
| + Новый чат      |                                  +--------------+  |
| ---------------- |                                                    |
| [Корейские блюда]| +-----------------------------------+              |
| Идеи для диеты   | |          [Изображение блюда]      |              |
|                  | | Пряная курица с овощами и рисом   |              |
|                  | | 540 ккал · 32г Б · 18г Ж · 58г У  |              |
|                  | | Время приготовления: 30 мин.      |              |
|                  | | Ингредиенты: ...                  |              |
|                  | +-----------------------------------+              |
|                  | Дальше просто рецепт...                            |
|                  |                                                    |
|                  | +------------------------------------------------+ |
|                  | | Напишите сообщение                         [^] | |
|                  | +------------------------------------------------+ |
| [Панель админа]  |                                                    |
+------------------+----------------------------------------------------+
```

- Активный чат в сайдбаре выделен фоном `surface-highlight` и скруглением `0.5rem`.
- Сообщение пользователя выровнено по правому краю, фон `primary`, текст `text-inverse`, скругление `0.75rem`.
- Ответ представлен карточкой рецепта шириной `min(100%, 28rem)`, с фоном `surface-1` и рамкой `border-main`.
- Изображение, название, пищевая ценность, время приготовления и ингредиенты оформлены согласно компоненту карточки рецепта в `components.md`.
- Текст рецепта расположен под карточкой, стиль `Body/Regular`, цвет `text-main`.
- Поле сообщения расположено у нижнего края основной области; кнопка отправки содержит иконку стрелки вверх.

### 2.5. Панель администратора — дашборд (`/admin`)

```text
+------------------+-----------------------------------------------------------+
| [||] ЧАТЫ        | [Всего пользователей] [Активные | Новые чаты | Сообщения] |
| ---------------- | [       247        ] [   64    |    312    |  1,315  ]    |
| + Новый чат      | [▲ 3,2% Рост за 7 дней] [Период: 1д  3д  (7д)  1м]        |
|                  | -----------------------------------------------------     |
|                  | [Найти пользователя...]       Сообщения: [7 дней v]       |
|                  | -----------------------------------------------------     |
|                  | Имя    Чаты Активные Сообщения За период Активность       |
|                  | user_1  31      4       123       87     2 часа назад     |
|                  | Aertna   8      1        97       26    1 месяц назад     |
|                  | -----------------------------------------------------     |
| [Панель админа]  | Записи 1–5 из 247   Страница 1 из 50    |< < > >|         |
+------------------+-----------------------------------------------------------+
```

- Сайдбар соответствует экрану чата.
- KPI-карточка «Всего пользователей» оформлена согласно компоненту KPI без выбора периода из `components.md`.
- Карточка показателей с периодом оформлена согласно компоненту KPI с выбором периода. В ней расположены показатели «Активные пользователи», «Новых чатов» и «Сообщений», а также переключатель периода `1д`, `3д`, `7д`, `1м`. Выбранный период выделен фоном `surface-highlight`.
- Строка фильтров содержит поле поиска пользователя и выпадающий фильтр периода сообщений.
- Таблица пользователей содержит колонки: `Имя`, `Всего чатов`, `Активные чаты`, `Всего сообщений`, `Сообщений за период`, `Последняя активность`.
- Заголовки и строки таблицы используют `text-main`; разделители — `border-main`.
- Нижняя панель таблицы оформлена согласно компоненту из `components.md`.
- Абсолютная дата активности отображается как текст подсказки рядом с относительной датой.

### 2.6. Панель администратора — карточка пользователя (`/admin/users/:id`)

```text
+------------------+----------------------------------------------------+
| [||] ЧАТЫ        | <- Назад                                           |
| ---------------- | Камелия  [Администратор]                           |
| + Новый чат      | В сети: 3 дня назад · Регистрация: 07.09.2026      |
|                  | +----------------------------------------------+   |
|                  | | Чатов: 20 | Активные: 13 | Сообщений: 173   |    |
|                  | +----------------------------------------------+   |
|                  |                                                    |
|                  | Чаты                       Последняя активность    |
|                  | -------------------------  --------------------    |
|                  | Идея ужина [Удален]        Создал чат «Японская»   |
|                  | Высокопрот... [Активен]    Отправил сообщение...   |
|                  |                                                    |
| [Панель админа]  | Записи 1–3 из 20    Страница 1 из 7     |< < > >|  |
+------------------+----------------------------------------------------+
```

- Шапка содержит кнопку «Назад», имя пользователя, бейдж роли, дату регистрации и время последней активности.
- Бейдж роли имеет фон `primary` и текст `text-inverse`.
- Плашка метрик показывает количество чатов, активных чатов и сообщений; фон `surface-1`, рамка `border-main`, скругление `0.5rem`.
- Основное содержимое разделено на две колонки: таблица чатов и список последних событий.
- Бейдж «Удален» использует `status-danger`; бейдж «Активен» — `status-success`.
- Нижняя часть страницы содержит пагинацию в соответствии с компонентом из `components.md`.
