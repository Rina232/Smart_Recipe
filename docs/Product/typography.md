# Типографика

## Семейства шрифтов

| Токен | Семейство шрифтов | Назначение |
|---|---|---|
| `heading` | Alegreya Sans | Заголовки |
| `paragraph` | Golos Text | Основной текст и абзацы |

## Начертания шрифта

| Токен | Насыщенность |
|---|---:|
| `extralight` | 200 |
| `regular` | 400 |
| `semibold` | 600 |

## Размеры шрифта

| Токен | Размер |
|---|---:|
| `xs` | 12 px |
| `sm` | 14 px |
| `md` | 16 px |
| `lg` | 18 px |
| `xl` | 24 px |
| `xxl` | 32 px |
| `xxxl` | 48 px |
