# Компоненты

Размеры в этом документе описывают макет и визуальные требования. Для размеров, которые должны масштабироваться вместе с текстом, используйте `rem`; для адаптивных размеров — проценты или `clamp()`. Фиксированные значения оставляйте там, где они заданы явно, например для тонкой рамки.

## Кнопка

Кнопка запускает действие или отправляет форму. Для перехода по ссылке используйте ссылку, а не кнопку. Текст кнопки должен кратко описывать действие.

### Варианты

| Вариант | Внешний вид | Когда использовать |
|---|---|---|
| `primary` | Заливка `primary`, светлый текст `text-inverse` | Для главного действия на экране |
| `secondary` | Фон `surface-1`, рамка и текст `primary` | Для дополнительного действия |

### Параметры

| Свойство | `primary` | `secondary` |
|---|---|---|
| Фон | `primary` | `surface-1` |
| Текст | `text-inverse` | `primary` |
| Рамка | Нет | `1px solid primary` |
| Скругление | `0.5rem` | `0.5rem` |
| Внутренние отступы | `0.5rem 0.75rem` | `0.5rem 0.75rem` |
| Расстояние между элементами | `0.5rem` | `0.5rem` |
| Стиль текста | `Label/Strong` | `Label/Strong` |

Текст и дополнительные элементы, например иконка, располагаются в одну строку и выравниваются по центру. Иконку показывайте только при необходимости. Если кнопка содержит иконку и текст, расстояние между ними — `0.5rem`.

## Поле ввода

Поле предназначено для ввода текстового значения. Подпись располагается над полем.

### Состояния

| Состояние | Фон поля | Рамка |
|---|---|---|
| `default` | `surface-1` | `1px solid text-main` |
| `focus` | `surface-1` | `1px solid primary` |

### Параметры

| Свойство | Значение |
|---|---|
| Скругление поля | `0.5rem` |
| Внутренние отступы поля | `0.5rem 0.75rem` |
| Расстояние между подписью и полем | `0.5rem` |
| Стиль подписи | `Label/Strong`; цвет `text-main` |
| Стиль текста внутри поля | `Body/Regular`; цвет `text-main` |

Подпись выравнивается по левому краю. Внутри поля элементы располагаются в одну строку и выравниваются по вертикали: ведущая иконка, текст и иконка справа. Расстояние между ведущей иконкой и текстом — `0.25rem`. Размер ведущей иконки — `1rem`, правой — `1.5rem`. Иконки используют цвет `text-main`.

## Всплывающая подсказка

Короткая подсказка, которая появляется рядом с элементом интерфейса и поясняет его назначение или состояние. Подсказка имеет фон, чтобы её текст был различим на фоне страницы.

### Варианты

| Вариант | Фон | Рамка | Текст |
|---|---|---|---|
| `default` | `surface-highlight` | `1px solid border-main` | `text-main` |
| `danger` | `status-danger` | Нет | `text-inverse` |

### Параметры

| Свойство | Значение |
|---|---|
| Скругление | `0.5rem` |
| Внутренние отступы | `0.375rem 0.5rem` |
| Выравнивание текста | По центру |
| Стиль текста | `Caption/Regular` |

## Боковая панель

Боковая панель предназначена для навигации по чатам и доступа к панели администратора. Поддерживает развёрнутое и свёрнутое состояния.

### Варианты

| Вариант | Ширина | Содержимое |
|---|---|---|
| `expanded` | `clamp(16rem, 20vw, 18.25rem)` | Заголовок «ЧАТЫ», кнопка сворачивания, кнопка «Новый чат», список чатов и нижний блок с кнопками |
| `collapsed` | `clamp(4rem, 5vw, 4.5rem)` | Кнопка разворачивания, кнопка создания чата, список чатов в виде иконок и нижний блок с кнопками |

### Параметры

| Свойство | Значение |
|---|---|
| Высота | `100vh` или высота родительского контейнера |
| Фон | `surface-1` |
| Правая рамка | `1px solid border-main` |
| Внешние отступы, развёрнутое состояние | `clamp(1rem, 2vw, 1.5rem)` |
| Внешние отступы, свёрнутое состояние | `1.5rem 0.75rem` |
| Расположение основных групп | Вертикально; нижний блок с кнопками прижат к нижнему краю |

На узких экранах панель может переходить в выдвижное наложение поверх основного содержимого.

### Содержимое

| Элемент | Развёрнутое состояние | Свёрнутое состояние |
|---|---|---|
| Заголовок | «ЧАТЫ», стиль `Heading/H3`, цвет `text-main` | Не отображается |
| Кнопка сворачивания/разворачивания | Иконка панели размером `1.25rem` | Иконка панели размером `1.25rem` |
| Разделитель | Ширина `100%` | Ширина `100%` |
| Создание чата | Иконка «плюс» размером `1.5rem` и текст «Новый чат» | Только иконка «плюс» размером `1.5rem` |
| Список чатов | Названия чатов текстом | Иконка чата для каждого элемента |
| Нижний блок | Кнопка панели администратора, если пользователь авторизован с ролью администратора; кнопка «Выйти» | Иконки доступных кнопок |

### Элемент списка чатов

| Состояние | Внешний вид |
|---|---|
| `default` | Прозрачный фон, стиль `Body/Regular`, цвет `text-main` |
| `selected` | Фон `surface-highlight`, скругление `0.5rem` |
| `hover` | Справа может отображаться иконка удаления; при наведении показывается подсказка «Удалить чат» |

В развёрнутом состоянии название занимает доступную ширину и переносится при необходимости. Иконка удаления масштабируется относительно текста, ориентир — `1.25rem`. В свёрнутом состоянии активный чат выделяется фоном `surface-highlight` и скруглением `0.5rem`.

| Расстояние между иконкой и текстом | `0.5rem` | Не применяется |

## Карточка рецепта

Карточка показывает изображение блюда, название, пищевую ценность, время приготовления и список ингредиентов.

### Параметры

| Свойство | Значение |
|---|---|
| Ширина | `min(100%, 28rem)` |
| Фон | `surface-1` |
| Рамка | `1px solid border-main` |
| Скругление | `0.75rem` |
| Расположение содержимого | Вертикально |
| Изображение | На всю ширину; соотношение сторон `3.4 / 1`; `object-fit: cover`; нижняя рамка `1px solid border-main` |
| Внутренние отступы содержимого | `clamp(1rem, 3vw, 1.5rem)` |
| Расстояние между основными блоками | `1rem` |

Высота карточки определяется содержимым. Изображение сохраняет заданное соотношение сторон и не растягивается по высоте карточки.

### Содержимое и типографика

| Элемент | Стиль и оформление |
|---|---|
| Название рецепта | `Heading/H2`, цвет `text-main` |
| Пищевая ценность | `Body/Regular`, цвет `text-main`; метрики разделены точками диаметром `0.25rem`, расстояние между ними — `0.5rem` |
| Время приготовления | Подпись `Body/Strong`, значение `Body/Regular`; расстояние между ними — `0.25rem` |
| Заголовок «Ингредиенты:» | `Body/Strong`, цвет `text-main` |
| Список ингредиентов | `Body/Regular`, цвет `text-main`; отступ слева `1rem`, расстояние между строками `0.5rem` |
| Маркер ингредиента | Точка диаметром `0.25rem`; расстояние до текста — `0.5rem` |

Блок ингредиентов располагается вертикально: расстояние между заголовком и списком — `0.75rem`. Список содержит ингредиенты с количеством.

## Индикатор надёжности пароля

Показывает визуальную оценку надёжности пароля с помощью трёх сегментов и подписи состояния.

### Параметры

| Свойство | Значение |
|---|---|
| Ширина | `100%` доступной ширины |
| Количество сегментов | 3 |
| Расстояние между сегментами | `1rem` |
| Высота сегмента | `0.5rem` |
| Цвет незаполненного сегмента | `surface-highlight` |
| Расстояние между сегментами и подписью | `0.5rem` |
| Стиль подписи | `Caption/Regular` |

Сегменты одинаковой ширины и делят доступное пространство поровну. Подпись располагается под ними и выравнивается по левому краю. Для пустого пароля отображаются три незаполненных сегмента без подписи.

### Состояния

После открытия страницы и при очистке поля показывается состояние `inactive`: все три сегмента имеют цвет `surface-highlight`, подпись отсутствует.

Во время ввода отображается одно из четырёх состояний надёжности:

| Состояние | Заполненные сегменты слева направо | Цвет заполненных сегментов | Подпись | Цвет подписи |
|---|---:|---|---|---|
| `very-weak` | 3 | `status-critical` | «Очень слабый пароль» | `status-critical` |
| `weak` | 1 | `status-danger` | «Слабый пароль» | `status-danger` |
| `medium` | 2 | `status-warning` | «Средний пароль» | `status-warning` |
| `strong` | 3 | `status-success` | «Сильный пароль» | `status-success` |

Незаполненные сегменты имеют цвет `surface-highlight`. Состояние `very-weak` отличается от `strong` цветом заполненных сегментов и подписью.

## Нижняя панель таблицы

Показывает диапазон отображаемых записей, текущую страницу и элементы навигации.

### Параметры

| Свойство | Значение |
|---|---|
| Ширина | `100%` доступной ширины |
| Минимальная высота | `1.5rem` |
| Расположение элементов | В одну строку, группы распределены по ширине |
| Выравнивание по вертикали | По нижнему краю |
| Шрифт текста | `Body/Regular`, цвет `text-main` |
| Размер иконок навигации | `1.5rem` |
| Расстояние между иконками в группе | `1rem` |
| Расстояние между группами навигации | `2rem` |

На узких экранах группы могут переноситься на следующую строку; порядок элементов сохраняется.

### Содержимое

| Элемент | Пример | Оформление |
|---|---|---|
| Диапазон записей | «Записи 1–5 из 247» | `Body/Regular`, цвет `text-main` |
| Текущая страница и общее количество страниц | «Страница 1 из 50» | `Body/Regular`, цвет `text-main` |
| Переход в начало и на предыдущую страницу | Иконки «к началу» и «назад» | Иконки размером `1.5rem`, расстояние `1rem` |
| Переход на следующую страницу и в конец | Иконки «вперёд» и «в конец» | Иконки размером `1.5rem`, расстояние `1rem` |

Цвет иконок — `text-main`. Группа навигации состоит из группы перехода назад и группы перехода вперёд. Подписи доступности кнопок должны описывать действие: «Первая страница», «Предыдущая страница», «Следующая страница» и «Последняя страница».

Показывает показатели, значения которых зависят от выбранного периода. Карточка включает переключатель временного диапазона.

### Параметры

| Свойство | Значение |

Показатели размещаются в адаптивной сетке. На узких экранах сетка может переходить на несколько строк, а переключатель периода — выравниваться по левому краю.
