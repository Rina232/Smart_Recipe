# Цвета

## Базовые цвета

Основная палитра. Цвета интерфейса должны ссылаться на эти значения, если это применимо.

| Токен | HEX-код |
|---|---|
| `cream-50` | `#FFFDF8` |
| `cream-100` | `#FAF7F0` |
| `cream-200` | `#F2E6D5` |
| `terracotta-500` | `#C94B3C` |
| `mustard-400` | `#E7B94E` |
| `herb-500` | `#6F9B62` |
| `charcoal-900` | `#29252A` |
| `taupe-300` | `#E4D9CC` |

## Цвета интерфейса

| Токен | Значение |
|---|---|
| `surface-0` | `color/primitive/cream-100` |
| `surface-1` | `color/primitive/cream-50` |
| `surface-highlight` | `color/primitive/cream-200` |
| `surface-primary` | `color/ui/primary` |
| `text-main` | `color/primitive/charcoal-900` |
| `text-muted` | `color/primitive/charcoal-900` с прозрачностью 30% |
| `border-main` | `color/primitive/taupe-300` |
| `primary` | `color/primitive/terracotta-500` |
| `secondary` | `color/primitive/mustard-400` |
| `tertiary` | `color/primitive/herb-500` |
| `text-inverse` | `color/primitive/cream-50` |
